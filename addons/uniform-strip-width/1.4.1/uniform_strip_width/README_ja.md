# Uniform Strip Width 1.4.1

**表側の帯を面選択 → 固定側A/Bを選択 →「幅を均一化」** の通常操作はそのままです。別枠に、取得したエッジの長さを使って幅を合わせる機能を追加しました。

## インストール・更新

旧版を無効にし、Blenderの「編集 > プリファレンス > アドオン > メニュー > ディスクからインストール」から `uniform-strip-width-v1.4.1.zip` を選び、有効にします。表示が旧版のままなら作業を保存してBlenderを再起動してください。NサイドバーのUSWで使用します。

## 使い方

1. 編集モードの面選択で、幅をそろえたい表側の帯を選択します。
2. 固定側をA/Bから選びます。Aは橙色、Bは水色の輪です。固定側の輪を大きく表示します。輪の表示にはビューポートのギズモを有効にします。
3. 「幅を均一化」を押します。選択した帯の最短横断辺の長さへ自動でそろえます。

固定側と最短の横断辺は動かしません。裏面の頂点も動かしません。周囲や側壁のNGON・シェイプキーは、そのまま残して使用できます。相対シェイプキーの変形差分を保持します。Undoに対応します。

## 表示する項目

目標幅が最短幅であること、Fixed Side A/B、色の説明、ギズモの案内、端点番号、面選択の案内、実行ボタンだけを表示します。厚み追従・NGON横断辺モードはありません。旧版で保存された詳細設定は使用しません。追加機能は下の「別のエッジの幅に合わせる」を開いたときだけ表示します。

## 対象と動作

選択する表面は1列につながる四角形の帯です。開いた帯・閉じた環状帯・3Dで湾曲した帯に対応します。帯自体のNGONを指定する専用モードはこの版にはありません。帯の周囲や裏側・端面にNGONがあっても、それを理由に対象全体を除外しません。

横断方向を選択面の接続から判定し、A/Bを自動で表示します。選択範囲を変えた場合は、その範囲に対して端点表示が更新されます。1面だけを選択した場合は接続から縦横を区別できないため、平均長が短い辺の組を幅方向とします。

幅はワールド座標で測る横断辺の直線距離です。対象範囲内の最短幅を実行時に測り、各移動側頂点を元の横断辺の線分上で固定側へ動かします。全体スケーリングや座標軸方向への移動は使用しません。接続・頂点数・面数・選択状態・UV座標は維持します。移動頂点を共有する側壁等の面は形が変わります。

空の面選択や、帯の対応を判定できない面選択、潰れが生じる形状等では、形状を変更する前に理由を通知します。あらゆる自己交差や他物体との衝突を検出する機能ではありません。共有メッシュ・読み取り専用・編集中キーのロックは尊重します。絶対シェイプキー、Windows、Linuxの網羅検証はしていません。

## 追加機能：別のエッジの幅に合わせる

USWパネル下部の **「別のエッジの幅に合わせる」** を開きます。最初は折りたたまれています。

1. 基準にするオブジェクトを編集モードで開き、エッジ選択で辺を **1本だけ** 選択します。
2. 「選択エッジの幅を取得」を押します。ワールド座標での長さと取得元名が表示されます。元のエッジやオブジェクトは変形しません。
3. 同じオブジェクトを対象にする場合は、そのまま面選択へ切り替えて対象の表側の帯を選びます。
4. 別のオブジェクトを対象にする場合は、Object Modeへ戻って対象を選び、Edit Modeで表側の帯の面を選択します。
5. 上のFixed Side A/Bで固定側を選び、「取得した幅に合わせる」を押します。

取得した幅は同じシーン内でオブジェクトを切り替えても保持します。取得後の元エッジの変更には自動追従せず、必要なときに取得し直します。通常の「幅を均一化」は引き続き選択帯の最短幅を使い、取得値には影響されません。

### 取得幅に合わせるときの動き

- **目標より太い箇所**：移動側頂点を、元の横断辺上で固定側へスライドします。
- **目標より細い箇所**：移動側頂点を、その頂点の **正の法線方向** へ動かします。固定頂点を中心とする目標幅の球との交点を求めます。
- **既に目標幅の箇所**：許容誤差内なら保持します。

法線は実行前のメッシュ全体から得られる頂点法線です。周囲や側壁に接続している頂点では、それらの面も法線に影響します。平らな帯では面から浮く方向への変形になります。幅としてそろえるのは両端のワールド直線距離です。

非一様スケール下では逆転置行列でワールド法線を求めます。固定側、裏面、対象外の頂点は動かしません。すべての頂点の移動を計算・検証した後に書き込むため、取得幅が無効、法線が無効、面や辺が潰れる等の場合は一部だけ変形させず中止します。両追加ボタンはUndoに対応します。

## 検証

macOSのBlender 5.0.0 / 5.2.2 LTSで従来25件と追加18件を実行し、すべて合格しました。5.0.0ではGUIで別オブジェクトからの取得と帯への適用・Undo、およびZIP展開版の43件、addon_utils有効化・無効化も検証しました。詳しくは配布フォルダーの検証結果.mdとvalidation内のログ・JSONを参照してください。

単一Pythonファイルのレガシー形式で、追加の依存はありません。通常操作は `mesh.uniform_strip_apply`、追加操作は `mesh.uniform_strip_capture_width` と `mesh.uniform_strip_apply_reference` です。利用者の作業中モデル・既存.blend・プリファレンス・スタートアップファイルは、この開発作業では変更していません。Windows・Linux・全Blender 5.x版・保存再読込後の継続操作は未検証です。


## 1.4.1の表示変更

サイドバーのタブ名を「USW」に変更しました。A/Bの丸いマーカーは、その3Dビューでサイドバーを開き、USWタブを表示している間だけ表示します。Nキーでサイドバーを閉じる、Item等の別タブに切り替える、Object Modeへ戻ると非表示になります。ギズモ全体を無効にする必要はありません。USWタブ内でパネルを折りたたんだ状態までは区別しません。
