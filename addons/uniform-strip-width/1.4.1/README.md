# Uniform Strip Width

帯状メッシュの片側を固定し、反対側の頂点だけを動かして幅をそろえるBlender用アドオンです。

## 主な機能

- 選択した1列の四角形の帯を、最短の横断エッジの幅へ自動でそろえます。
- 固定側A/Bを選択でき、橙色と水色のマーカーで固定側を確認できます。
- 同じオブジェクトや別オブジェクトの1本のエッジから幅を取得して合わせられます。
- 取得した幅に合わせる際は、太い箇所を横断エッジ上でスライドし、細い箇所を正の頂点法線方向へ移動します。
- 頂点数・面数・接続関係・選択状態・UV座標を維持し、相対シェイプキーの変形差分を保持します。
- マーカーはUSWタブを表示している間だけ表示され、別タブやサイドバーを閉じた際に隠れます。

## インストール

BlenderのPreferences → Add-ons → メニュー → Install from Diskで配布ZIPを選び、有効化します。 単体.pyファイルを配布している場合は、その.pyを解凍せず同じメニューで選択しても導入できます。

## 使い方

1. ZIPを解凍せず、BlenderのPreferencesのAdd-onsからInstall from Diskで導入し、有効にします。
2. 編集モードで、幅をそろえたい表側の1列の四角形の帯を面選択します。
3. NキーでサイドバーのUSWタブを開き、Fixed Side AまたはBを選択します。
4. 「幅を均一化」を押すと、選択帯の最短幅へそろいます。
5. 任意の幅へ合わせる場合は「別のエッジの幅に合わせる」を開き、エッジ1本から幅を取得して対象帯の面を選び「取得した幅に合わせる」を実行します。

## 対応環境

設定上の最低バージョン: Blender 5.0.0。実際の確認環境はTEST_RESULTS.jsonを参照してください。

## 制約・未検証

- 対象は1列につながる四角形の帯です。分岐・複数列・帯自体のNGONには対応しません。
- 幅は横断エッジ両端のワールド直線距離で、表面に沿った長さではありません。
- 取得幅より細い箇所は正の頂点法線方向へ動くため、平面では面から浮く変形になります。
- 移動頂点を共有する側壁などの面も形が変わります。
- 複数オブジェクトの同時編集、共有メッシュ、リンク・オーバーライド・読み取り専用データには対応しません。
- 絶対シェイプキー、Windows・Linux、全Blender 5.x、保存再読み込み後の継続操作は未検証です。
- あらゆる自己交差や他物体との衝突を検出する機能ではありません。
- 今回はバックグラウンド検証です。開発時のGUI・Undo確認とスクリーンショット撮影は参照チャット・検証記録に基づきます。
