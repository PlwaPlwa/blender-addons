# Bevel Weight Quick Set 1.1.0

## インストール・更新

インストール対象は `bevel_weight_one.py` だけです。旧版との互換性のためファイル名は維持しています。

1. 旧版が有効な場合は、Blenderのプリファレンス → アドオンで旧版を無効化します。
2. アドオン画面右上のメニュー →「ディスクからインストール / Install from Disk」で `bevel_weight_one.py` を選択し、旧ファイルを置き換えます。
3. 必要に応じてBlenderを再起動し、`Bevel Weight Quick Set` を有効にします。

## 操作

メッシュの編集モードでエッジ選択を有効にし、対象エッジを選んで3Dビュー内を右クリックします。

- **Set Bevel Weight to 1.0**: 選択エッジを1.0に設定します。
- **Set Bevel Weight to 0.0**: 選択エッジを0.0に設定します。

いずれもダイアログなしで即時実行し、未選択エッジの既存値は変更しません。複数オブジェクトの同時編集に対応し、共有メッシュは一度だけ処理します。選択エッジがあるメッシュで `bevel_weight_edge` がなければ、EDGE/FLOAT属性を作成します。その場合、未選択エッジは新規属性の既定値0.0になります。

メニュー、オペレーター名、ツールチップ、アドオン名、説明、エラー文はすべて英語です。本説明書のみ日本語です。追加の設定画面や入力プロパティはありません。

UndoはBlender標準のUndoを使用します。今回のmacOS標準キーマップではCommand+Zで検証しました。Ctrl+Zの割当ては環境のキーマップに従います。

## 自動テストの再実行

`test_bevel_weight.py` とアドオン本体を同じフォルダーに置いて実行します。

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python test_bevel_weight.py
```

このテストは実行先のシーンをテストデータに置き換えます。新規のバックグラウンドプロセスで実行してください。結果は同じフォルダーの `automated_results.json` に保存されます。GUIのメニュー表示・クリック・Undoはこのスクリプトの自動検証対象外で、今回別途実機検証しています。
