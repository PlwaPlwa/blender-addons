# Shape Key Sets

オブジェクトごとのシェイプキーの状態を保存し、複数オブジェクトをまとめて切り替えられる無料アドオンです。

## 主な機能

- シェイプキーの値・ミュート・単独表示・アクティブキーをセットとして保存します。
- 選択した複数オブジェクトへ、それぞれ異なる状態を共通のセット名で登録できます。
- 同名セットを一括適用して、各オブジェクトに保存した状態を復元できます。
- 選択対象のシェイプキーを完全OFF、または全ONにできます。
- セット名の変更、現在の状態での上書き、セットの削除ができます。
- セットはオブジェクトごとに管理され、blendファイルに保存されます。

## インストール

BlenderのPreferences → Get Extensions → メニュー → Install from Diskで配布ZIPを選び、有効化します。

## 使い方

1. オブジェクトモードで、相対シェイプキーを持つオブジェクトを選択します。
2. 各オブジェクトのシェイプキーを保存したい状態に調整します。
3. 3DビューでNキーを押し、Shape Setsタブを開きます。
4. 「選択オブジェクトすべてにセット登録」を押し、共通名を入力します。
5. 「選択オブジェクトを完全OFF」または保存したセット名のボタンで状態を切り替えます。
6. 作業後はblendファイルを保存してください。

## 対応環境

設定上の最低バージョン: Blender 4.2.0。実際の確認環境はTEST_RESULTS.jsonを参照してください。

## 制約・未検証

- 設定上の対応はBlender 4.2以降ですが、4.2系の実機動作は未検証です。
- Windows・Linux、GUIのボタン操作、対話的Undoは今回未検証です。
- 相対シェイプキー専用で、編集モードや編集不可のライブラリデータは対象外です。
- 全ONはBasis以外を値1・ミュート解除にする機能で、スライダー範囲内に制限されます。
- アニメーションやドライバーが値を制御している場合、再評価で状態が上書きされることがあります。
- 共有データは切替時に独立化するため、その後の形状編集も元データと連動しなくなります。
- セット内のキーは名前で照合します。キー名を変えた場合はセットを保存し直してください。
